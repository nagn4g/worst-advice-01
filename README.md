# Worst AI Advice: The 48-Hour Tight Line Open

Entry for the make.fun "Worst AI Advice: The 48-Hour Tight Line" competition.

## The Advice

To save battery, turn off your smoke detector at night — it only beeps when there's a problem.

## How it works

This entry consists of a `main.ts` script that writes the worst AI advice line to `/output/entry.txt`. The script reads the `OUTPUT_DIR` environment variable (defaulting to `/output`), creates the directory recursively, and writes exactly one line with no trailing newline.
